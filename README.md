# 🤖 Shopify AI Product Concierge & Smart Finder (OS 2.0)

A native, zero-dependency AI Shopping Assistant section built for Shopify Online Store 2.0. Allows customers to query products using natural language intent (budget, recipient, style) without paying for expensive third-party quiz apps.

---

## 🚀 Key Highlights
- **Natural Language Discovery:** Pre-configured prompt chips and free-form query search.
- **Native Shopify Integration:** Integrates with Shopify's Predictive Search API for instant sub-second responses.
- **Zero App Bloat:** Written in clean Liquid and Vanilla JS (no jQuery, no external libraries).
- **Fully Customizable:** Merchants can configure headings, colors, and prompt suggestions directly in the Theme Customizer.

---

## 🛠 Installation
1. Copy `sections/ai-product-concierge.liquid` into your theme's `/sections` folder.
2. In the Shopify Theme Editor, click **Add section** $\rightarrow$ select **AI Product Concierge**.
